Restaurar base de datos

Sube un archivo SQLite con extensión .db. No subas un .tar.gz desde este formulario; para las copias locales usa el botón Restaurar de la lista de Administración.

La base actual se guarda como kmtracker.db.bak. Si la validación o las migraciones fallan, se recupera automáticamente esa copia.

Tamaño máximo: {{ max_upload_mb }} MB. Directorio de copias: {{ backup_dir }}.

Si la base viene de otra instalación

No copies solo el archivo kmtracker.db mientras la aplicación de origen está funcionando: puede tener datos pendientes en el WAL. Crea una copia consistente con:

sqlite3 /ruta/kmtracker.db ".backup '/ruta/kmtracker_produccion.db'"

Después sube kmtracker_produccion.db aquí.
